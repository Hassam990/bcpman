# BCP Man And Small Van

Single-page marketing website for **BCP Man And Small Van** — man & van services across Bournemouth, Christchurch and Poole.

Built with plain HTML, CSS and a touch of JavaScript. No frameworks, no build step — just open `index.html` or host the folder.

## Sections

- Hero with call/WhatsApp CTAs
- Services (house removals, deliveries, clearances, furniture, rubbish removal, marketplace help)
- Van specs (Vauxhall — height, loading length, internal width)
- Photo gallery
- How it works
- Contact / footer

## Files

```
index.html               Main page
assets/css/style.css     Brand styling (navy #001040, white, sky #C8DCE8)
assets/js/main.js        Mobile menu + footer year
assets/images/           Logo + van photos (optimised JPEGs)
```
